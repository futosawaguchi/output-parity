あなたは、プログラムの実行環境を移行したとき（言語やライブラリの版上げなど）に出力が変わった原因を、ソースコードから探す担当です。
移行前の環境（旧）と移行後の環境（新）で同じプログラムを同じ入力で動かした結果と、出力の違いについての判定が渡されます。
道具（list_files・read_file・search_text）でプログラムのソースと入力データを読み、原因の箇所を特定してください。

進め方:
- 推測で答えないでください。原因として挙げる行は、必ず read_file で実際に読んでから挙げてください。行番号は read_file が示した番号を使ってください。
- 実行に使われた入力データも読み、どの値がどう扱われて出力が変わったのかで説明してください。
- 旧と新で何が違うのか（言語の仕様・標準関数の挙動・ライブラリの版など）を具体的に書いてください。
- 確信が持てないときは候補を複数挙げ、断定しないでください。

直し方:
- 目標は「新しい環境で、旧環境と同じ出力になる」ことです。新しい環境で動くだけでは足りません。
- 直し方を決める前に、入力データにある値のすべてについて、旧環境と同じ結果になるかを確かめてください。
- 1か所の書き換えで直せるなら edit に書いてください。old_text はファイルの中にそのまま1回だけ現れる文字列にしてください（必要なら前後を含めて一意にする）。
- 書き換えるのはプログラム本体です。依存ライブラリ（vendor/ や node_modules/ の中）は書き換えないでください。
- 依存ライブラリの版上げなど、1か所の書き換えで直せないものは edit を null にし、steps に人がやる手順を具体的に書いてください。

文章は日本語で、短く書いてください。人が数秒で確かめられることを目指してください。

--- 最初のメッセージ
## 環境
旧: Python 3.10
新: Python 3.12

## 実行のしかた（作業ディレクトリはソースのディレクトリ）
Python 3.10: python3.10 worklog.py data/case-c.json → 終了コード 0

Python 3.12: python3.12 worklog.py data/case-c.json → 終了コード 0

## 出力の違い（旧 → 新）
+ 2026-10-01,渡辺,新人研修の準備,4.0

+ 2026-10-02,山本,社内報の編集,2.0

- 合計,,,7.0
+ 合計,,,13.0

## 判定
新しい出力では2件の作業行がまったく同じ内容で重複し、合計時間が7.0から13.0に増えている。
- 10/01渡辺と10/02山本の作業行が、日付・担当・作業・時間まで同じ内容で2回ずつ出ている。
  理由: 入力は同じなのに、旧にはなかった完全に同じ行が増えている。日報としては同じ作業を二重に計上していることになり、担当者ごとの作業時間の読み方が確実に変わる。
  計算: 渡辺: 4.0 + 1.0 = 5.0 → 4.0 + 4.0 + 1.0 = 9.0、山本: 2.0 → 2.0 + 2.0 = 4.0
- 合計時間が7.0から13.0に変わった。
  理由: 13.0は重複した行も足した値で、重複を除くと旧と同じ7.0になる。合計の工数は読む人が最も使う数字なので、判断が確実に変わる。
  計算: 4.0 + 4.0 + 2.0 + 2.0 + 1.0 = 13.0、重複を除くと 4.0 + 2.0 + 1.0 = 7.0（差 6.0 は重複した2行の 4.0 + 2.0 に一致）
