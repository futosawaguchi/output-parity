# 安全と Claude に送るもの

## 安全について

- **本番環境には接続しません。** 出力をローカル環境で作って比べるツールです
- 書き換えるのは作業用のコピー `work/` だけです。元のソースにも本番にも触れません。元のソースへ入れる流れは「[仕組み](how-it-works.md#直したあと元のソースへ)」にあります
  - `work/<名前>/` は `source` を丸ごと写したもので、このリポジトリの中にあります（`.gitignore` 済み）。`.env` などもそのまま写ります（Claude には読ませません）。写したくなければ `fixes: "suggest-only"` にします（その場で動かし、ツールは何も書きません。試すプログラム自身が書くファイルは、元のソースに残ります）
  - ソースの中のシンボリックリンクは、リンクのまま写します。ソースの中を指すリンクは `work/` の写しを、外を指すリンクは元の場所を指します。ツールが直し方を書くときは、リンクをたどって元のソースや外へ書き込むことはしません。試すプログラムがリンクの先（外を指すリンクや、`workspace.link` で写さずにリンクする `vendor`・`node_modules` など）に書き込むのは止めません
- **作った結果をファイルに残して使い回す（キャッシュする）システムは対象外です。** 旧と新は同じフォルダで動き、入力ごとに戻すのは Web 型の設定の `database` だけです。旧が書いたキャッシュを新が読むと、新の出力が旧と同じになり、違いが見えなくなります
- 直し方を当てるのは、UTF-8 で書かれたソースだけです。Shift_JIS などで書かれたファイルには当てず、パッチも作りません（日本語が壊れるため）。示された直し方を見て、手で直してください
- **Claude にファイルを書くツールを渡していません。** 書くのは、人がボタンを押したときのツールのコードです
- ローカル環境では、画面は `127.0.0.1` だけで開きます。`127.0.0.1`・`localhost`・`[::1]` 以外の Host で来た要求は断ります（DNS リバインディング対策）
- 公開環境では、この確認の代わりに、アクセスコードを入れた人だけが使えるようにします。プログラムの実行と、コピーへの書き込み（当てて確かめる）は、画面だけでなくサーバ側でも断ります

## Claude に送るもの

設定の `claude.send` で選びます。**既定はありません**（書かないと止まります）。何を送るかは、押す前に画面に出ます。

| `claude.send` | 判定 | 原因探し |
|---|---|---|
| `none` | 送りません。機械で決まるもの（差なし・出力なし・読めない）だけ判定し、ほかは未判定として並べます | 使えません |
| `output` | 新しい出力の全文・変わった行（旧の側も）・PDF のレイアウトの値（文字の座標から求めた値）・環境名と終了コード | 使えません |
| `output-and-source` | 同上 | 判定・変わった行・実行のしかた・標準エラー出力の先頭と、Claude が選んで読んだソースと入力データ |

- **読ませない範囲**: `.env`・鍵・証明書・`.git` などは、設定にかかわらず読ませません。`claude.neverRead` で足せます（減らせません）。リンクは実体の場所で判断します。名前の大文字と小文字は区別しません（`server.KEY` も読ませません）
- **呼ぶ回数の守り**: Claude を呼ぶのは、機械で決まらなかった入力だけです（差なし・出力なし・読めないは機械が決めます）。1件につき1回呼び、新しい出力の全文を送ります。それが **10 件を超えるときは1件も送らずに止め**、件数を見せて、押されてから送ります（コマンドでは `--judge-all`）
- **長い出力**: 10 万字を超えるときは、変わった行の前後 30 行ずつだけを送り、そのことをプロンプトと画面に書きます
- **読み取れない返事**: Claude の返事が途中で切れるなどして読み取れなかった入力は、ほかの入力を止めずに「要確認」にします
- **伏せ字**: 送る前に、パスワード・キー・トークンらしい値を `***` にします。**これは網であって保証ではありません。** 名前も決まった形も無いパスワードは通ります。伏せたあとで旧と新が同じになる変更は、Claude には違いが見えないので、Claude の答えにかかわらず「要確認」にします
- **送った全文を残します**: `runs/sent/` に、伏せ字のあとの全文を残します。画面の各結果からも開けます
- **試すプログラムに渡す環境変数**: `PATH`・`HOME`・ロケールなど起動に要るものと、設定の `env` だけです。API キーは渡しません
  - ただし、試すアプリが**親のフォルダまで `.env` を探す**作り（Python の `python-dotenv` の `load_dotenv()` など）だと、`work/` はこのリポジトリの中にあるので、ツールの `.env`（API キー）を読めてしまいます。そういうアプリを試すときは、ツールの `.env` を使わず、キーを環境変数で渡してください
- **試すアプリ自体の外への接続（本番の DB・メール送信など）は、このツールでは止められません。** ネットワークを切るか、接続先をテスト用にしてから動かしてください
- **設定を一緒に書くスキル**（`.claude/skills/try-your-system`）を使うと、Claude Code が読んだソースは、`claude.send` にかかわらず Claude に送られます。`claude.send` が決めるのは、このツールが判定と原因探しで送るものです
- 送ったデータの扱いは Anthropic の規約に従います

## このツールが言えること・言えないこと

言えるのは、試した入力について、移行の前後で出力が同じになったことと、差があったものを理由つきで確かめたことです。次のことは言えません。

- 試していない入力については何も言えません
- 出力以外の副作用（DB の更新・メール送信）は見ていません
- 見た目は一部しか見ません。「差なし」は、**ツールがテキストにした部分**に差が無いという意味です
  - 見るもの: 文字・ページ数・用紙・画像の数（PDF と HTML）・用紙からのはみ出し、PDF のフォームの欄の値と、`%PDF-` の前や `%%EOF` のうしろに混ざった文字（PHP の警告など）、HTML のフォームの値（select は選べる選択肢も）と表の中の画像の alt、テキストの改行コード・先頭の BOM・最後の改行
  - 見ないもの: 文字の重なり・色・太字、PDF の罫線・図形・バーコード・グラフ（SVG を含む）、画像の中身（数だけ数えます）、フォントの置き換わり（字形が無くて豆腐になっても、文字としては同じに読めます）、HTML の属性だけの変化（リンク先 `href`・選択肢の `value`・`hidden`・`disabled` など）、PDF の中で文字が動いたことと文字の大きさの変化（同じ高さの中で左右に動いても、行の順が変わらない範囲で上下に動いても、用紙からはみ出さない限り大きさが変わっても、差になりません）、JavaScript があとから書く文字（HTML はサーバの応答をそのまま読み、スクリプトは動かしません）、画像・CSS・JavaScript のファイルが届くかどうか、出力をファイルに書く設定での標準出力と標準エラー出力
  - 隠された要素の中の文字は、見える文字と区別せずに比べます
  - 文字コードとして読めない部分（� になった部分）があれば、差が見つからなくても、Claude が「無害」と答えても、「要確認」にします
- 「無害」は Claude の判断です。機械が確かめるのは、Claude が書いた計算（足し算と引き算）が合うことと、引用が出力にあることだけです。計算も引用も無い「無害」は、そのまま「無害」になります
- 終わり方（終了コード・HTTP の状態・移動先、Web 型では Content-Type と Content-Disposition も）が旧と新で違えば、出力が同じでも、Claude が「無害」と答えても、「要確認」にします
- 毎回変わる値（日時・ID など）は、新を2回動かして見つけ、変わった部分だけを除きます。ただし、区切りの無い固定長の行で金額が日時のすぐ前にくっついていると、金額の変化も一緒に除かれることがあります。また、分・時・日付の単位で書かれた日時が、旧と新を動かすあいだに繰り上がると、その違いが残って判定に回ることがあります
- ローカル環境で一致しても、本番で保証したことにはなりません。言語の細かいバージョン・拡張・設定（php.ini など）・ロケールは同じではありません

## 確かめた入力の記録

試していない入力については何も言えないので、**どの入力で何を確かめたか**を1枚に残せます。

- 画面の一覧の上の「確かめた記録を見る」で開き、「Markdown で保存」で保存できます。コマンドなら `npm run record -- --subject <名前>` です（最新の実行の `runs/<id>/record.md` に書きます。同梱の結果は `--bundled`・`--bundled-fix`）
- 中身: 結論（このまま移せるか）・出どころ（この環境で実行したか、同梱の結果か）・旧と新の環境・入力ごとの終わり方と残った差・毎回変わる値として除いた差（例つき）・判定・当てた直し方・Claude に送ったもの・上の「言えないこと」のうち主なもの
- 判定の無い入力も落とさず書きます。直し方を当てたあとは、「当てる前の判定」を新しい判定と分けて書きます
- 実行コマンドの場所は書かず、環境の名前（`label`）だけを書きます。リポジトリの中のパスは相対に、ホームは `~` にします。それ以外の絶対パスはそのまま残ります。鍵に見える値は `***` にします。出力の抜き書き（金額・名前）は含むので、人に渡す前に読んでください
- 参考として、**新の環境でだけ出た「廃止予定」の警告**（PHP の `Deprecated`、Python の `DeprecationWarning` など）を数えます。数えた結果は判定に使わず、Claude にも送りません（原因探しでは、標準エラー出力の先頭として警告が届くことがあります）。いまの出力が同じでも、次にバージョンを上げたときに壊れる候補です。Python は読み込んだモジュールの `DeprecationWarning` を既定では出さないので、見るなら設定の `args` に `-W default` を足してください
